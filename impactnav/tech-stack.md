# tech-stack.md

Kullanılan / önerilen teknolojiler

- PHP 8.x — sunucu tarafı mantık
- MySQL — ilişkisel veritabanı
- Docker & docker-compose — geliştirme ve taşıma için konteynerizasyon
- Git + GitHub — sürüm kontrolü
- Vercel — statik frontend / hızlı snapshot deploy (NOT: PHP LAMP için önerilmez)
- Render / Railway / DigitalOcean App Platform — PHP backend için tavsiye edilen production sağlayıcıları

Nedenler

- PHP seçildi: mevcut kod tabanı PHP ile yazılmış.
- Vercel hızlı statik yayın için uygundur; backend için Render gibi bir sağlayıcı daha stabil ve düşük sürprizlidir.
