# features/

Bu klasörde projeye ait kaynak kodlar ve yardımcı dosyalar bulunur. (Örnek altyapı - zorunlu dosyalar şunlardır):

- `index.php` — proje ana giriş dosyası
- `db.php` — veritabanı bağlantısı
- `register.php` / `login.php` — kullanıcı yönetimi
- `listing-create.php` / `listing-view.php` — listeleme işlemleri
- `api/` — API uç noktaları (chat, match vb.)

Not: Repo zaten bu dosyalara sahipse, bu klasör sadece açıklama amaçlıdır. Kodlar kaynak dizininde olduğu için burada tekrar kopyalanması gerekli değildir.
